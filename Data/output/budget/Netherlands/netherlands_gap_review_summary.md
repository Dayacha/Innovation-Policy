# Netherlands Gap Review Summary

Main diagnosis:
- The country is not primarily failing because files are absent. Many problematic years did run and produced rows.
- The largest unresolved issue is structural: several source families provide only aggregate policy blocks, especially `OCW Art. 16` for NWO/KNAW and shifting innovation totals across EZ/LNV.
- A smaller but real pipeline issue was present in canonical selection, where `review` rows could override better `include` rows. That has now been corrected.
